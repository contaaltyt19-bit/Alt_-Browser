# Alt_-Browser
The browser that says "Privacy is convenience!"

Important thing before you open and be surprised:

- the browser is being updated, so don't worry, you can tell us about any bug or feature that is missing in our youtube channel, yapper, aduna and discord
- the browser is completly free, and we don't need any money from it.
